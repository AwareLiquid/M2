# 液态世界模型探针（入口 B · 换拟合目标）

> 状态：🟡 设计完成（脚本待上传运行）
> 定位：M1/M2 的入口 B（换拟合目标）最小实证——**拟合"世界的下一个状态"，不是下一个 token**。
> 依据：liquid-research-skill 共识——"只要拟合目标是 next-token，一切架构改动都是量变；
> 换拟合目标是质变的唯一入口"。

## 核心问题

**只用物理状态轨迹训练（无任何 token），液态模型能否学会世界的动力学——多步"想象"是否追得上真实轨迹？**

## 设计

| 层 | 组件 | 来源 |
|---|---|---|
| 世界 | 谐振子/单摆轨迹（physics_ops.rollout，N 条不同初始条件） | M1 `physics_ops.py` |
| 骨干 | 小液态编码器（2 层液体块）→ 隐状态 (B,T,d) | O1-Flash 同款 |
| 拟合目标 | **状态预测**（PredictiveStateHead：h_t → h_{t+1} 的潜表示，BYOL/V-JEPA 式 stop-grad EMA 目标） | M1 `world_model.py` |
| 评估 | **多步想象**（LatentImagination：把学会的一步映射滚动 H 步）vs 真实未来 vs "静止不动"基线 | M1 `imagination.py` |

**全程无 next-token**：输入是状态向量，目标是下一状态，评估是想象轨迹的跟踪误差。

## 预注册判据

- **H 成立** ⇔ 想象轨迹在 H=16 步的跟踪误差 < "静止基线"误差的 0.5×（模型真的学会了动力学，
  不是记住常数）；且误差随想象视野的增长斜率 < 基线斜率（滚动是"移动的"，不是发散的）
- **诚实边界**：物理真值（解析积分器）是天花板——模型学不到比辛积分更准的动力学；
  本探针证明的是"从状态数据中学到动力学"（拟合目标换轨可行），不是"超越解析物理"

## 产出

- `benchmarks/world_model_probe.py`：可跑脚本（合成轨迹，零数据文件，CPU 可跑）
- 想象误差曲线（模型 vs 静止基线 vs 视野 H）
- 判定：状态预测拟合目标是否让液态栈学会真实动力学
