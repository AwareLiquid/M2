# 预测编码闭环探针（入口 C 换办法 · 液体基底上的脑式环路）

> 状态：🔴 **DEAD（2026-09-20 全量判定）**——误差门控反馈损害世界模型
> （想象误差 0.466→0.890，ratio16 0.384→0.882）；冒烟时的优势是小配置噪声。
> 缘由：入口 C 第一招（LIF-SNN 小世界递归）在 sMNIST 上 0.66 vs GRU 0.96 判负——
> 微尺度递归连接不是脑式环路的实质。换办法：**用入口 B 刚验证的液体基底（状态预测），
> 加上预测编码的闭环（预测→误差→反馈）**——这正是大脑最根本的环路（Friston）。

## 判定记录

| 模式 | 想象误差 @H16 | 判定 |
|---|---|---|
| 开环（纯前向预测） | 0.466（基线 1.215） | SUPPORTED |
| 闭环（误差门控） | 0.890（基线 1.008） | **DEAD** |

**解读**："惊讶抑制输入"这个最小预测编码闭环在平滑动力学上不成立——训练好的
世界模型误差已经很小（gate≈1 无作用），而两遍训练的误差回灌扰动了梯度。误差
门控不是这个基底上正确的环路形态。下一候选：**海马固化环（离线重放）**——
M2 已验证的 genreplay 机制，有实证基础。

## 核心问题

**预测误差反馈进处理回路（闭环），能否比开环（纯前向预测）延长想象轨迹的可靠视野？**

## 设计

| 组件 | 开环（已有） | 闭环（本探针） |
|---|---|---|
| 骨干 | 液体衰减扫描（多尺度 τ） | 同 + **误差门控**：上一时刻的预测误差调制下一时刻的输入增益 |
| 拟合目标 | 状态预测（JEPA） | 同 |
| 环路 | 无 | **pred_error → input gate**（惊讶信号回流，大脑"预测编码"的最小闭环） |

## 预注册判据

- **闭环成立** ⇔ 闭环模式的想象可靠视野（误差 < 阈值 0.3 的最大 H）> 开环视野的 1.5×；
- 否则如实记 DEAD（"误差反馈无增益"）。

## 实现要点

- 在 `world_model_probe.py` 的 LiquidBlock 加 `error_gate`：输入 u 乘以
  `(1 - pred_error_prev)`——上一时刻的惊讶按比例减弱下一时刻的输入
- pred_error 来自 PredictiveStateHead 的 `last_pred_error`（现成字段）
- 开环/闭环共用同骨架同预算，仅差门控通路
