## 解读

- 与 M2 的 genreplay 实证不一致的原因候选：M2 的持续学习是**文本**（生成质量高、
  梯度信号密集），本探针是**低维动力学**（2 维状态，噪声主导）。
- 固化环方向在更强信号域（文本/高维状态）仍可能有价值，但本探针形态到此结案。

## 设计

- 世界：两个不同周期的谐振子（k=4 与 k=9——动力学 A/B）
- 模型：液体骨架 + JEPA 头（同世界模型探针）
- 协议：Phase 1 学 A → Phase 2 学 B，三臂对照：
  1. `no_replay`：Phase 2 只喂 B
  2. `real_replay`：Phase 2 混合喂 B + A 的真实轨迹（重放）
  3. `genreplay`：Phase 2 混合喂 B + **模型自己生成**的 A 轨迹（生成式重放——
     用 Phase 1 学到的动力学想象 A，无需存储）
- 指标：Phase 2 结束后对 A 的想象跟踪误差（遗忘度量）——重放臂应显著低于 no_replay

## 预注册判据

- **固化环成立** ⇔ real_replay 与 genreplay 对 A 的跟踪误差均 < no_replay 的 0.7×；
- genreplay 与 real_replay 的差距（生成的代价）如实记录（M2 实测 +0.016 的量级）。

## 诚实边界

- 双任务（A→B）是最小的持续学习场景；真实脑式固化是多任务长序列，这是探针不是复刻。
- genreplay 生成的 A 轨迹来自模型自己的想象——若 Phase 1 学得好，生成近似真实；
  生成误差对固化的影响正是要测量的量。
