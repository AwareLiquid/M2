# 混合梦回放（reservoir）替代方案 — FAIL（4/6），但压平了反转

针对 order_sensitivity 的反转（顺序 201 GRU 更好）的替代方案：**唯一变量 =
梦池跨任务保留（reservoir）**——每阶段结束后把新梦追加进池，回放从"全部
历史梦"采样（混合旧+新），而非只用最新一阶段的梦。其余协议与基线完全一致
（6 排列 × PC/GRU × 3 seeds，worst_final）。

## 结果对比

| 顺序 | 基线 PC−GRU | mix PC−GRU | 变化 |
|---|---|---|---|
| 012 | −0.0134 | −0.0155 | ≈ |

| 102 | −0.1143 | −0.0535 | ↓ |
| 120 | −0.1850 | −0.0738 | ↓ |
| 201 | **+0.0805** | **+0.0141** | 反转几乎消失 |
| 210 | −0.0124 | +0.0011 | 变中性 |
| **PC 胜** | 5/6 | **4/6** | |
| **判定** | FAIL | **FAIL** | |

## 解读

1. **设计目标达成一半**：反转幅度从 +0.0805 压到 +0.0141（≈噪声量级）、
   210 也归零——reservoir 确实消除了"最难任务在前"时的大幅反转；
2. **但代价是 PC 优势整体缩小**（102/120 的 −0.11/−0.19 → −0.05/−0.07）：
   混合旧梦稀释了"最新状态梦"的作用，PC 与 GRU 的差异被抹平到 ±0.07 内；
3. 净效果：**两种回放策略下 PC 均不超过 4-5/6 顺序占优；"全顺序占优"的
   严格判据在合成域达不到**。

## 结论与口径

- 与 genreplay_stability（3/5 seeds）、order_sensitivity（5/6）合并：
  **PC 生成式回放的均值优势可复现，但顺序/seed 稳健性不成立**；
- 残余信号（201 顺序下 GRU 微优 +0.014）量级≈seed 噪声，已排 5-seed
  复跑做统计确认（`order_sens_mix5.log`）；若 5-seed 下仍为正，则论文
  写"hardest-task-first 下无差异（|Δ|≤0.02）"，不写机制保证。
